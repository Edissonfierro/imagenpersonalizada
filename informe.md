## 3. Fundamentos

### ¿Qué es Vite?
Vite es una herramienta de desarrollo frontend que permite construir y servir aplicaciones modernas como React con una velocidad de arranque y recarga en caliente muy rápida.

### ¿Qué es Docker?
Docker es una plataforma que permite contenerizar aplicaciones, es decir, empaquetarlas junto con todas sus dependencias para ejecutarlas de forma aislada en cualquier sistema que tenga Docker instalado.

### ¿Qué es MockAPI?
MockAPI es un backend simulado que expone rutas de prueba para que aplicaciones frontend puedan interactuar con datos sin necesidad de un servidor real.

## 5. Objetivos a alcanzar

- Clonar el repositorio de frontend basado en Vite.
- Ejecutar el frontend localmente.
- Crear un `Dockerfile` adecuado para contenerizar la app.
- Generar una imagen Docker a partir del Dockerfile.
- Ejecutar un contenedor que sirva el frontend.
- Verificar que la app cargue correctamente en el navegador (`localhost:3000`).
- Ejecutar el backend simulado (MockAPI) para que el frontend funcione correctamente.
